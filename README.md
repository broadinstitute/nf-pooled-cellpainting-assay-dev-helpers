# nf-pooled-cellpainting-assay-dev-helpers

Marimo notebooks for making parts of running nf-pooled-cellpainting jobs easier (currently, samplesheet creation and viewing QC reports); plan is to also add aws helper scripts. 

[![Open QC viewer in molab](https://marimo.io/molab-shield.svg)](https://molab.marimo.io/github/nf-pooled-cellpainting-assay-dev-helpers/blob/main/view_qc.py)

Notebooks are designed to be run sandboxed; see [this page](https://docs.marimo.io/guides/package_management/sandboxes/) on the Marimo docs for uv and pixi execution instructions.
