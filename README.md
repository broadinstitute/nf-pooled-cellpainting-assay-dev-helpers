# nf-pooled-cellpainting-assay-dev-helpers

Marimo notebooks for making parts of running nf-pooled-cellpainting jobs easier (currently, samplesheet creation and viewing QC reports); plan is to also add aws helper scripts. 

While a pixi environment is also included, notebooks are designed to also be run sandboxed when desired; see [this page](https://docs.marimo.io/guides/package_management/sandboxes/) on the Marimo docs for uv and pixi execution instructions.
